# 设计文档（事实）

本目录描述系统 **当前的真实状态**，必须与代码保持一致。

## 子目录

| 路径 | 内容 |
|---|---|
| `api.yaml` | OpenAPI 格式的接口定义 |
| `db-schema.md` | 数据库表结构与索引说明 |
| `domain-model.md` | 领域模型：聚合、实体、值对象、关系 |
| `topic/` | 单点技术专题（鉴权、状态机、业务规则、数据字典……） |

## 维护规则

- 改了接口 → 更新 `api.yaml`
- 改了表结构 → 更新 `db-schema.md`
- 改了业务规则 → 更新 `topic/businessrule.md`
- 改了数据字典 → 更新 `topic/data-dict.md`
- 新增专题 → 在 `topic/` 下新建文件，并在本表登记
