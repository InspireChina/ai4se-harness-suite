# 编写原型

对照 `docs/features/<迭代>/<CODE>-<slug>/spec.md` 的字段和页面，做一版原型。

## 输出

- 原型放在 `docs/features/<迭代>/prototypes/`
- 在原型目录的 README 里写清怎么启动、端口、对应哪份 spec

## 硬性约束

- 没有 spec 就停止
- 不改后端实现
- 同一份 spec 已经有原型时，只补缺的页面，不另起一套
