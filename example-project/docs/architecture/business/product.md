# 产品定义与高阶概念

> 项目级产品边界与核心概念。迭代范围见 [`iterations.md`](./iterations.md)；核心领域见 [`core-domain-model.md`](./core-domain-model.md)。  
> 维护：`ba-arch-plan` 起草；`ba-arch-sync-back` 迭代后对齐。

## 一句话

线上 **咨询师预约平台**：用户找咨询师、看档案、选时段、下单预约、履约、评价与结算。

## 三端

| 端 | 角色 | 核心能力 |
|---|---|---|
| 用户端 | 终端用户 | 检索、预约、支付相关流程、评价 |
| 咨询师端 | 咨询师 | 入驻、档期、履约、结算 |
| 管理端 | 平台管理员 | 审核、分类与治理 |

## 本期不做（产品边界）

- 原生 App / 小程序
- 音视频通话
- 跨境结算、发票税务对接

## 高阶概念

| 概念 | 含义 |
|---|---|
| 咨询师档案 | 可被检索与展示的服务供给方资料 |
| 可约时段 | 咨询师开放、可被占用的时间片 |
| 预约单 | 用户对某时段的下单与履约载体 |
| 履约 | 预约完成后的服务交付与状态流转 |
| 结算 | 咨询师侧佣金/收益结算 |

术语权威列表见 [`glossary.md`](./glossary.md)。
