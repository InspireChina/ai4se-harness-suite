# E2E 测试用例 — 咨询预约平台

> **归属：QA 测试。** 本文件是 QA 验收用例的 **文本基线**，由 QA 定义与判定。
>
> - 自动化实现位于 `e2e/tests/qa/app.spec.ts`，编号与本文件一一对应
> - 自动化代码可由开发代写，但用例的 **定义权与判定权归 QA**
> - 需求规格的每条验收标准（`docs/features/*/§12`）与每条业务规则（`R-xxx`）都必须有对应用例
> - **合并闸门**：本文件的用例未全部通过验收，不能合并

> **不属于本文件的**：开发自测用例放在源码旁与 `e2e/tests/dev/`，只对开发本人负责，不是验收依据。

## 1. 公共页面

| # | 用例 | 步骤 | 预期 |
|---|---|---|---|
| TC-001 | 首页加载 | 访问 `/` | 页面显示标题"专业咨询服务"、"免费注册"、"立即预约"按钮、版权信息 |
| TC-002 | 登录页渲染 | 访问 `/login` | 显示邮箱/密码输入框、登录按钮、注册链接 |
| TC-003 | 注册页渲染 | 访问 `/register` | 显示姓名/邮箱/手机/密码输入框、注册按钮、登录链接 |
| TC-004 | 公开 API 可用 | GET `/api/v1/data-dictionaries`、`/api/v1/business-rules`、`/api/v1/consultants` | 均返回 200，咨询师列表 ≥ 3 条 |
| TC-005 | 导航跳转 | 首页点击"登录" → 点击"立即注册" | URL 依次变为 `/login` → `/register` |

## 2. 认证

| # | 用例 | 步骤 | 预期 |
|---|---|---|---|
| TC-006 | 管理员登录成功 | 填写 admin@test.com / password → 提交 | 跳转到 `/admin/dashboard`，显示"管理仪表盘" |
| TC-007 | 错误密码提示 | 填写 admin@test.com / wrongpassword → 提交 | 显示错误提示 |

## 3. 用户流程

| # | 用例 | 步骤 | 预期 |
|---|---|---|---|
| TC-011 | 用户仪表盘 | 登录后访问 `/user/dashboard` | 显示"总预约"、"待确认"、"已完成"统计卡片 |
| TC-012 | 浏览咨询师 | 访问 `/user/book` | 显示张医生、李律师、王教练三条记录 |
| TC-013 | 预约 + 取消 | 选咨询师 → 选日期 → 选时间 → 填备注 → 提交 → 取消 | 预约成功跳转预约列表 → 取消后显示"已取消"状态 |
| TC-014 | 编辑个人信息 | 访问 `/user/profile` → 修改姓名 → 保存 | 弹出"保存成功"提示 |

## 4. 管理员流程

| # | 用例 | 步骤 | 预期 |
|---|---|---|---|
| TC-015 | 仪表盘统计 | 管理员登录 → 访问 `/admin/dashboard` | 显示用户数 / 咨询师 / 总预约 / 待确认 / 网点五个卡片 |
| TC-016 | 用户管理 | 访问 `/admin/users` | 表格显示 admin@test.com、管理员；可点击禁用/启用 |
| TC-017 | 咨询师管理 | 侧栏点击"咨询师管理" | 表格显示张医生、李律师、王教练 |
