# E2E 测试用例（QA）

> **归属：QA 测试。** 判定权与定义权归 QA。  
> 自动化实现见 `e2e/tests/qa/`，编号一一对应。  
> 需求来源：`docs/features/iteration1/ACC-account/spec.md`（AC-001～AC-005 / R-CREATE-* / R-QUERY-* / R-UPDATE-* / R-DELETE-*）。

## 说明

- 运行环境：`bash e2e-run.sh`（前端 :5173 + 后端 :8080）。
- 测试环境验证码：Mock 短信通道固定码 `123456`（后端 `SMS_MOCK_FIXED_CODE`）。
- 平台管理员种子账号：`13900000000` / `Admin@12345`（后端 `seed.admin.*`）。
- 每个用例使用独立手机号，避免同号登录态互相干扰。

## ACC · 账号与个人中心

### TC-001 手机号验证码注册登录

| 项 | 内容 |
|---|---|
| 关联 | AC-001、R-CREATE-001 |
| 前置 | 未登录；手机号 `1{随机 10 位}` 未注册 |
| 步骤 | 1. 打开 `/user/login`；2. 输入手机号，点击「获取验证码」；3. 输入验证码，勾选协议；4. 点击「登录 / 注册」 |
| 预期 | 1. 提示验证码已发送；2. 登录成功并跳转到 `/user/profile`；3. 个人中心展示昵称、手机号；4. 账号角色为 USER，状态 active |

### TC-002 验证码错误时拒绝登录

| 项 | 内容 |
|---|---|
| 关联 | R-CREATE-002、EX-001 |
| 前置 | 未登录；已获取验证码 |
| 步骤 | 1. 打开 `/user/login`；2. 输入手机号与错误验证码 `000000`；3. 点击「登录 / 注册」 |
| 预期 | 登录被拒绝，页面提示「验证码错误」，停留在登录页，未产生登录态 |

### TC-003 修改个人资料后仍然生效

| 项 | 内容 |
|---|---|
| 关联 | AC-002、R-UPDATE-001 |
| 前置 | 已登录（TC-001 的账号） |
| 步骤 | 1. 进入 `/user/profile`；2. 修改昵称、邮箱、城市并保存；3. 刷新页面 |
| 预期 | 1. 保存成功提示；2. 刷新后昵称 / 邮箱 / 城市为最新值 |

### TC-004 未登录访问个人中心被拦截

| 项 | 内容 |
|---|---|
| 关联 | PR-001 |
| 前置 | 未登录（清空本地登录态） |
| 步骤 | 1. 直接访问 `/user/profile` |
| 预期 | 被重定向到 `/user/login`，不展示个人中心内容 |

### TC-005 收藏咨询师

| 项 | 内容 |
|---|---|
| 关联 | AC-003、R-CREATE-004 |
| 前置 | 已登录 |
| 步骤 | 1. 进入 `/user/profile`；2. 在「我的咨询师」输入可展示咨询师 ID `stub-consultant-001`；3. 点击「收藏」 |
| 预期 | 提示收藏成功，收藏列表出现该咨询师；重复点击收藏不报错且列表不重复 |

### TC-006 取消收藏（幂等）

| 项 | 内容 |
|---|---|
| 关联 | AC-003、R-DELETE-001 |
| 前置 | 已收藏 `stub-consultant-001` |
| 步骤 | 1. 在收藏列表点击「取消收藏」并确认；2. 再次对同一咨询师执行取消 |
| 预期 | 1. 列表不再展示该咨询师；2. 重复取消不报错，仍为空列表 |

### TC-007 协议同意记录

| 项 | 内容 |
|---|---|
| 关联 | AC-004、R-CREATE-003 |
| 前置 | 已登录并完成协议勾选 |
| 步骤 | 1. 登录（勾选协议）；2. 进入 `/user/profile` 查看「协议同意记录」 |
| 预期 | 分别记录服务协议与隐私政策，含协议版本、同意时间与来源 IP；重复登录不产生重复记录 |

### TC-008 管理员禁用账号后旧会话失效

| 项 | 内容 |
|---|---|
| 关联 | AC-005、R-UPDATE-003、EX-002 |
| 前置 | 用户已登录；管理员账号可用 |
| 步骤 | 1. 用户登录并停留在个人中心；2. 管理员以 `13900000000` 登录并禁用该用户账号（原因「QA 禁用」）；3. 用户刷新个人中心 |
| 预期 | 1. 禁用成功且账号状态为 disabled；2. 用户旧会话被拒绝（401），前端清除登录态并跳回登录页；3. 该账号再次登录被拒绝并提示账号不可用 |

### TC-009 非管理员不得调用管理端接口

| 项 | 内容 |
|---|---|
| 关联 | PR-003、R-COMMON-001 |
| 前置 | 以普通用户登录 |
| 步骤 | 1. 使用普通用户令牌调用 `POST /api/v1/admin/accounts/{id}/disable` |
| 预期 | 返回 403，用户角色不能自提权或禁用他人账号 |
