# 手动执行用例 — 咨询预约平台

> **归属：QA 测试。** 自动化难以覆盖、或需要人工主观判断的场景写在这里。
> 由 QA 定义与判定，是 **合并闸门** 的一部分。

## 用例清单

| # | 用例 | 前置条件 | 步骤 | 预期 | 执行人 |
|---|---|---|---|---|---|
| TC-M01 | 后台禁用用户后其登录态失效 | 存在普通用户 `user@test.com` | 管理员禁用该用户 → 用户端刷新页面 | 用户被强制登出，跳转登录页 | |
| TC-M02 | 同一时段重复预约的提示文案 | 已有 咨询师A + 某时段 的预约 | 用另一账号预约同一时段 | 提示"该时间段已被占用"，errorCode = `APPOINTMENT_CONFLICT` | |
| TC-M03 | 移动端视口下布局不塌陷 | 已登录 | 视口宽度调至 375px | 首页与预约页排版正常，无横向滚动条 | |
| TC-M04 | 弱网下的加载态 | 浏览器限速 Slow 3G | 打开预约列表 | 显示加载态骨架，不出现空白页 | |
| TC-M05 | 刷新后表单草稿保留 | — | 在个人资料页填写昵称但不保存 → 刷新 | 昵称仍在输入框中 | |
