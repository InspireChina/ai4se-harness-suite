## 1. 需求说明

### 1.1 需求名称

账号与个人中心

### 1.2 需求类型

NEW

### 1.3 版本信息

| 项目 | 内容 |
|---|---|
| 基线版本 | 无 |
| 目标版本 | v0.1 |

### 1.4 背景

三端共用统一账号体系，终端用户需自助注册与维护资料；管理员账号由平台分配；咨询师权限在入驻审核通过后开通。

### 1.5 目标

打通注册登录、角色权限开通与个人资料维护，作为其余业务模块的前置能力。

### 1.6 范围

本次包含：

- 手机号验证码注册 / 登录（终端用户）
- 管理员账号平台分配与独立鉴权
- 咨询师审核通过后自动开通咨询师端权限
- 个人资料维护（昵称、头像、邮箱、城市）
- 我的咨询师收藏列表与取消收藏
- 服务协议 / 隐私政策同意记录

本次不包含：

- 第三方 OAuth、生物识别登录
- 完整 RBAC 权限配置后台（管理端仅操作级权限预留，细则见 platform-capability）

## 2. 功能说明

术语表见 [项目术语表](../../../architecture/business/glossary.md)。

### 2.1 功能概述

统一账号承载 USER / CONSULTANT / ADMIN 三类身份；用户端提供个人中心与收藏；咨询师端访问受入驻审核状态约束。

### 2.2 适用用户

| 用户角色 | 角色说明 | 使用场景 |
|---|---|---|
| USER | 终端用户 | 注册登录、改资料、管理收藏 |
| CONSULTANT | 咨询师 | 审核通过后登录咨询师端 |
| ADMIN | 管理员 | 使用平台分配账号登录管理端 |

### 2.3 主要业务对象

| 业务对象 | 说明 |
|---|---|
| Account | 统一账号（手机号、状态、角色集合） |
| UserProfile | 终端用户资料 |
| FavoriteConsultant | 用户收藏的咨询师 |
| AgreementConsent | 协议同意记录 |

## 3. 用户角色与权限

| 角色 | 可查看 | 可新增 | 可编辑 | 可删除 | 可审批 | 说明 |
|---|---:|---:|---:|---:|---:|---|
| USER | 是 | 是（注册） | 是（本人资料） | 否 | 否 | 仅本人数据 |
| CONSULTANT | 是 | 否 | 是（本人资料，档案细则见 onboarding） | 否 | 否 | 未审核通过不可进咨询师端 |
| ADMIN | 是 | 否 | 否 | 否 | 否 | 账号由平台分配 |

### 3.1 权限规则

- PR-001：未登录不可访问需鉴权接口。
- PR-002：咨询师审核未通过前不可访问咨询师端。
- PR-003：管理端接口独立鉴权。
- PR-004：未提及的操作一律不允许。

## 4. 业务流程

### 4.1 主流程

1. 用户输入手机号获取验证码并完成校验。
2. 系统创建/登录账号，默认角色为 USER。
3. 用户维护个人资料；可收藏/取消收藏咨询师。
4. 用户首次使用前完成协议同意记录。

### 4.2 异常流程

| 编号 | 触发条件 | 系统行为 | 结果 |
|---|---|---|---|
| EX-001 | 验证码错误或过期 | 拒绝登录/注册 | 返回明确错误 |
| EX-002 | 账号被禁用 | 拒绝登录 | 提示账号不可用 |
| EX-003 | 咨询师未审核通过访问咨询师端 | 拒绝访问 | 403 + 原因 |

## 7. 业务规则

1. **R-CREATE-001（手机号账号）**：注册时手机号须通过格式校验且全局唯一；已有手机号走登录流程，不重复创建账号。
2. **R-CREATE-002（验证码）**：验证码须匹配手机号、未过期且未使用；连续失败 5 次后该验证码失效。
3. **R-CREATE-003（协议同意）**：首次进入受保护功能前，必须分别记录当前版本服务协议与隐私政策的明示同意。
4. **R-CREATE-004（收藏幂等）**：同一用户与咨询师只能有一条收藏；重复收藏返回已有结果。
5. **R-QUERY-001（本人数据）**：个人资料、收藏与协议记录仅本人或具备审计权限的管理员可查询。
6. **R-QUERY-002（敏感脱敏）**：非账号本人查看时手机号、邮箱必须按平台规则脱敏。
7. **R-UPDATE-001（资料权限）**：仅本人可修改昵称、头像、邮箱、城市；账号 ID、手机号、角色不可由用户修改。
8. **R-UPDATE-002（咨询师授权）**：入驻申请 approved 后系统幂等增加 CONSULTANT 角色；驳回不授权。
9. **R-UPDATE-003（账号禁用）**：仅管理员可禁用/启用账号，禁用必须填写原因并使现有会话失效。
10. **R-DELETE-001（取消收藏）**：仅收藏人可取消收藏；重复取消按成功处理。
11. **R-COMMON-001（管理员账号）**：ADMIN 账号只能由平台分配，不开放自助注册或角色提升。
12. **R-COMMON-002（默认拒绝）**：未明确授权的账号、角色及资料操作一律拒绝并记录安全日志。

## 12. 验收标准

- **AC-001**：Given 新手机号已取得有效验证码，When 用户提交注册，Then 系统创建 active 账号、授予 USER 角色并返回登录态。
- **AC-002**：Given 用户已登录，When 修改合法的昵称、头像、邮箱或城市，Then 资料保存成功且再次查询返回最新值；越权修改他人资料被拒绝。
- **AC-003**：Given 用户收藏了可展示咨询师，When 打开收藏列表并取消收藏，Then 列表先展示该咨询师，取消后不再展示，重复取消不报错。
- **AC-004**：Given 用户尚未同意当前协议版本，When 首次进入受保护功能，Then 系统要求同意并分别保存协议类型、版本、时间与来源 IP。
- **AC-005**：Given 管理员已禁用账号，When 该账号登录或使用旧会话访问受保护接口，Then 系统拒绝访问并展示账号不可用原因。
